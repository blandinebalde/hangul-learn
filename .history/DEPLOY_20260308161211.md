# Déploiement GitHub Pages

## 1. Sur GitHub : configurer Pages

1. Ouvre ton dépôt → **Settings** (Paramètres).
2. Dans le menu de gauche, clique sur **Pages**.
3. Dans **Build and deployment** :
   - **Source** : **Deploy from a branch**
   - **Branch** : **main** (ou **master**)
   - **Folder** : **/docs**
4. Clique sur **Save**.

## 2. Lancer le déploiement

- Fais un **push** sur **main** (avec ce fichier et le workflow).  
- Ou va dans **Actions** → **Deploy to GitHub Pages** → **Run workflow**.

Le workflow va **builder** le site et **mettre le résultat dans le dossier `docs/`** sur ta branche. Après 1–2 minutes, le site est à jour.

## 3. Adresse du site

**https://blandinebalde.github.io/hangul-learn/**

(Si ton dépôt ne s’appelle pas exactement `hangul-learn`, remplace par le nom du dépôt.)

## Dépannage

- **Toujours 404** : vérifie que **Folder** est bien **/docs** et que la branche est **main** (ou **master**).
- **Workflow en erreur** : onglet **Actions** → clique sur le run en rouge → regarde quelle étape échoue et le message d’erreur.
