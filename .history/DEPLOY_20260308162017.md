# Déploiement GitHub Pages

**Important** : le site doit être servi depuis le dossier **/docs** (fichiers buildés), pas depuis la racine (code source). Si tu vois une 404 sur `main.jsx`, c’est que Pages sert encore la racine.

## 1. Sur GitHub : configurer Pages

1. Ouvre ton dépôt → **Settings** (Paramètres).
2. Dans le menu de gauche, clique sur **Pages**.
3. Dans **Build and deployment** :
   - **Source** : **Deploy from a branch**
   - **Branch** : **main** (ou **master**)
   - **Folder** : **/docs**
4. Clique sur **Save**.

## 2. Lancer le déploiement

- Fais un **push** sur **main** (avec ce fichier et le workflow).  
- Ou va dans **Actions** → **Deploy to GitHub Pages** → **Run workflow**.

Le workflow va **builder** le site et **mettre le résultat dans le dossier `docs/`** sur ta branche. Après 1–2 minutes, le site est à jour.

## 3. Adresse du site

**https://blandinebalde.github.io/hangul-learn/**

(Si ton dépôt ne s’appelle pas exactement `hangul-learn`, remplace par le nom du dépôt.)

## Dépannage

- **404 sur main.jsx** : Pages sert la mauvaise source. Vérifie que **Folder** est bien **/docs** (pas « root »). Sauvegarde et attends 1–2 min.
- **Nom du dépôt** : si ton dépôt ne s’appelle pas `hangul-learn`, modifie `base` dans `vite.config.js` (ex. `base: "/mon-repo/"`), puis refais un build et push.
- **Workflow en erreur** : onglet **Actions** → run en rouge → ouvre l’étape qui échoue pour voir l’erreur.
