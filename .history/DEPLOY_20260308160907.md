# Déploiement GitHub Pages (hangul-learn)

## Méthode : branche gh-pages

Le workflow **build** le projet et **pousse le résultat** sur la branche `gh-pages`. Le site doit être servi à partir de cette branche.

## Réglages sur GitHub

1. Ouvre ton dépôt → **Settings** → **Pages**.
2. **Build and deployment** > **Source** : choisis **« Deploy from a branch »**.
3. **Branch** : `gh-pages` — **Folder** : `/ (root)`.
4. Enregistre (**Save**).

## Déploiement

- À chaque **push sur main** (ou **master**), le workflow tourne, build le site et met à jour la branche `gh-pages`.
- Tu peux aussi lancer le workflow à la main : **Actions** → **Deploy to GitHub Pages** → **Run workflow**.

Après 1–2 minutes, le site est à jour à :  
**https://blandinebalde.github.io/hangul-learn/**

## Si tu as encore une 404

- Vérifie que la branche **gh-pages** existe (elle est créée au premier run du workflow).
- Vérifie que **Pages** utilise bien la branche **gh-pages** et le dossier **root**.
- Regarde l’onglet **Actions** : le workflow doit être **vert**. Si une étape est rouge, ouvre-la pour voir l’erreur.
